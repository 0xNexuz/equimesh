1. Protocol Overview

EquiMesh is a non-custodial, policy-governed autonomous portfolio manager for tokenized equities and Real World Assets (RWAs) built natively on the BNB Smart Chain (BSC Mainnet).

2. The 24/7 Weekend Trading Gap

The hackathon brief notes:

"Friday, 4pm, New York. The closing bell rings and every stock price in the country freezes until Monday. On-chain, nothing stops. The tokenized stocks trade straight through the weekend, priced off a reference that has not updated in two days. Anyone can see the gap, and almost nobody has built anything that acts on it."

When traditional markets close, tokenized equities on BSC (such as bStocks NVDA, AAPL, TSLA) continue trading 24/7 based on real-time market sentiment and crypto-native liquidity. If macro events occur over the weekend, on-chain spot prices diverge dramatically from the stale Friday oracle price.

The Solution: EquiMesh implements an autonomous hedging loop. When weekend divergence exceeds configured volatility thresholds, the agent rebalances excess equity exposure into an Ondo USDY cash buffer (earning 5.15% APY), protecting vault depositors from violent Monday opening-bell gap-downs.

3. The Dual Sovereignty Model

Most DeFi automation fails because of two extremes:

  1. Pure Manual Trading: Too slow to react to 24/7 weekend events or algorithmic arbitrage.
  2. Black-Box Autonomous Bots: Users surrender private keys or full custody, exposing funds to runaway slippage, flash loan exploits, or bot errors.

EquiMesh adopts Dual Sovereignty (embodied in the project's visual charter):

  • The Human Hand: Crafts and signs the immutable Policy Charter. Sets max slippage bounds (e.g. 100 bps), single-trade ceilings ($5,000), allowlisted assets, and retains an unconditional emergency circuit breaker.
  • The Robotic Agent Hand: Operates within those bounded limits 24/7. Evaluates market conditions, pays for intelligence via x402, simulates routes via Binance Web3 Wallet, and submits spot swaps on BSC Mainnet.

4. BNB Agent Studio & x402 Self-Funding

EquiMesh integrates directly with the BNB Agent Studio framework:

  • Agent Decentralized Identity: Registered as did:bnb:agent:equimesh-v1-mainnet with verifiable on-chain metadata.
  • Autonomous Trigger Runtime: Scheduled cron and event-driven triggers evaluate basket drifts every 15 minutes.
  • x402 Micropayment Protocol: The agent does not rely on free or centralized API feeds. Instead, before executing a rebalance, the agent sends an HTTP 402 micro-settlement ($0.01 USDT) to the decentralized sentiment oracle, obtaining a cryptographically signed price attestment.
// x402 Micro-settlement handshake implementation
const response = await fetch("https://oracle.equimesh.bnb/v1/market-sentiment", {
  headers: {
    "X-Agent-Identity": "did:bnb:agent:equimesh-v1-mainnet",
    "X-Payment-Signature": await agentSigner.signMicropayment(0.01, "USDT")
  }
});
const marketProof = await response.json(); // Validated before policy check

5. Binance Web3 Wallet AI Execution Layer

Trades are executed through the Binance Web3 Wallet Skill toolkit:

  • Transaction Simulation: Before broadcasting any transaction, the agent simulates the exact state delta, validating expected slippage, gas costs (BNB), and resulting token balances.
  • Spot Swap Routing: Automatically routes between BSC Mainnet pools for bStocks, xStocks, and Ondo USDY with lowest price impact.
  • Receipt Generation: Every swap produces a verifiable audit certificate containing input/output token deltas, execution timestamp, and BSCScan link.

7.2 Friction Points & Recommendations for Sponsors

  1. RWA & Tokenized Stock Contract Addresses: Currently, bStocks and xStocks contract addresses on BSC are scattered across documentation. Providing a single unified NPM SDK or canonical JSON registry (e.g. @bnb-chain/rwa-registry) would reduce onboarding friction by 70%.
  2. Simulation Revert Decoders: When a simulated transaction fails due to slippage caps, the RPC returns a generic hex revert string. Adding human-readable error parsing to the Binance Web3 Wallet simulation endpoint would dramatically simplify debugging for agent developers.
  3. x402 Micropayment Client Libraries: The HTTP 402 header negotiation pattern is brilliant for autonomous agents, but currently requires hand-crafted signature headers. We recommend releasing a lightweight wrapper like @bnb-chain/agent-x402.
