# 06. Sponsor Map — EquiMesh

| Sponsor / Protocol | Technology Used | Load-Bearing Integration | Hackathon Prize Alignment |
|---|---|---|---|
| **Binance Web3 Wallet** | Aggregated API Surface & Wallet Skills | Used for market data queries, swap routing, and pre-flight transaction simulations. | **Stack Special 1 ($2,000):** Best Use of Agentic Wallet / Wallet Skills |
| **BNB Chain** | BNB Agent Studio & BSC Mainnet | Hosts agent identity (`did:bnb:agent`), autonomous trigger scheduling, and x402 micropayments. | **Stack Special 2 ($2,000):** Best Use of BNB Agent Studio |
| **bStocks / xStocks** | Tokenized Equities on BSC | Core spot trading assets (bNVDA, bAAPL, bTSLA, bMSFT). Continuous 24/7 liquidity. | **Core Mandatory Requirement:** Must feature bStocks, Ondo, or xStocks |
| **Ondo Finance** | Ondo USDY (Yield-bearing Treasury Token) | Yield buffer reserve. Idle cash generates 5.15% APY instead of suffering inflation drag. | **Core Mandatory Requirement:** Must feature bStocks, Ondo, or xStocks |

## Sponsor Technology Load-Bearing Test
- **What happens if Binance Web3 Wallet skills are removed?** The agent loses transaction simulation, slippage estimation, and aggregated spot routing, breaking the automated execution loop.
- **What happens if BNB Agent Studio & x402 are removed?** The agent loses its decentralized identity, autonomous execution schedule, and ability to pay for real-time market sentiment feeds.
- **What happens if bStocks and Ondo are removed?** The entire product thesis (bridging 24/7 tokenized stocks with yield-hedged baskets) ceases to exist.
